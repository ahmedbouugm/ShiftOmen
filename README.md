# ShiftOmen

ShiftOmen leverages cloud-based, containerized architecture to deliver a dynamic, auto-scaling data pipeline optimizer and predictive modeling engine.

With ShiftOmen, you get a lightweight tool that stays out of your way.

**What you get**

- ShiftOmen leverages cloud-based, containerized architecture
- to deliver a dynamic, auto-scaling
- data pipeline optimizer and predictive

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ShiftOmen.git`
2. `cd ShiftOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ShiftOmen, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
